# 契約: デザイントークン（Platform）

画面の見た目の値の正。実装は `src/app/globals.css` の CSS 変数で、この表と同じ値を持つ。値を変えるときは、先にこの表を変え、コントラストを計算し直す（research.md の「コントラストの計算」と同じ方法）。部品の中に色の値を直接書かない。

## 色

### 面と文字

| トークン | 用途 | 明るい表示 | 暗い表示 |
|---|---|---|---|
| `--surface` | ページの背景（駅のコンクリート / 夜のホーム） | `#F3F5F6` | `#10181D` |
| `--panel` | 地図・表・グラフの領域、メニュー | `#FFFFFF` | `#18232A` |
| `--panel-muted` | 選んでいない状態、表の見出しの行 | `#E7EBEE` | `#22303A` |
| `--ink` | 本文と見出し | `#1B2A35` | `#E4EAED` |
| `--ink-muted` | 補足の文字 | `#5A6772` | `#98A6B0` |
| `--rule` | 区切りの細い線、入力欄の枠（飾り。情報は持たせない） | `#C9D0D5` | `#2C3A44` |
| `--focus` | キーボードのフォーカスの輪（2px + 2px の隙間） | `#0B63CE` | `#7CC4FF` |

### 路線色

路線を表すためだけに使う（帯・線・点・地図の線と列車の印）。**文字の色には使わない**（明るい表示でも背景との比が 4.5 に届かないものがあるため）。帯の上に文字を載せるときは、下の「帯の上の文字」を使う。

| トークン | 路線 | 明るい表示 | 暗い表示 | 帯の上の文字（明るい / 暗い） |
|---|---|---|---|---|
| `--line-red` | Red, Mattapan | `#DA291C` | `#F0564A` | `#FFFFFF` / `#10181D` |
| `--line-orange` | Orange | `#ED8B00` | `#ED8B00` | `#1B2A35` / `#10181D` |
| `--line-green` | Green-B〜E と合算 | `#00843D` | `#2FB46A` | `#FFFFFF` / `#10181D` |
| `--line-blue` | Blue | `#003DA5` | `#5B8DEF` | `#FFFFFF` / `#10181D` |
| `--line-stale` | 更新の止まった列車の印 | `#8A969F` | `#6C7A84` | — |

明るい表示は MBTA の路線色そのもの。暗い表示は、同じ色相で明るくし、`--panel` に対して 3:1 以上（図形）にした。

### 重要度（色に頼らない）

| トークン | 用途 | 値 |
|---|---|---|
| `--stripe` | 遅延系のアラート・データが古いときの帯の斜めの縞（45°、6px 間隔）。`--ink` と `--panel` の 2 色で描く | 明るい・暗いとも `--ink` / `--panel` |
| `--danger` | 取得の失敗などのエラーの文字（アイコンと文言を必ず添える） | `#B42318` / `#FF8A80` |

遅延系とお知らせ系、正常と問題ありは、**縞の有無 + アイコン（警告の三角 / 情報の丸 / チェック）+ 文言**で区別する。色だけで区別させない。

### グラフ（003 で検証した配色を保つ）

| トークン | 明るい表示（背景 `#FFFFFF`） | 暗い表示（背景 `#18232A`） |
|---|---|---|
| `--chart-1` | `#2A78D6` | `#3987E5` |
| `--chart-2` | `#EB6834` | `#D95926` |
| `--chart-grid` | `#E1E0D9` | `#2C3A44` |
| `--chart-axis` | `#898781` | `#98A6B0` |
| ヒートマップ（1 色の段階、薄い → 濃い） | `#CDE2FB` … `#0D366B`（7 段） | `#184F95` … `#CDE2FB`（逆順。暗い背景では明るいほど大きい） |

暗い表示の 2 色は、dataviz の検証（色覚の差、普通の見え方の差、明るさの帯、彩度、背景との比）をすべて通した（2026-11-05）。

## 書体

| トークン | 値 |
|---|---|
| `--font-sans` | `"Overpass Variable", system-ui, sans-serif`（`@fontsource-variable/overpass` の latin と latin-ext） |
| 数字 | 時刻・分数・件数・表の数値は `font-variant-numeric: tabular-nums` |
| 太さ | 本文 400、強調 600、見出し 800 |

### 文字の大きさの段階（1.25 倍）

| トークン | px | 行の高さ | 用途 |
|---|---|---|---|
| `--text-xs` | 13 | 1.4 | 補足、軸、表の数値 |
| `--text-sm` | 16 | 1.5 | 本文、入力、ボタン |
| `--text-md` | 20 | 1.4 | 小見出し、凡例の路線名 |
| `--text-lg` | 25 | 1.25 | 画面の見出し、板の行先 |
| `--text-xl` | 31 | 1.15 | 駅のページの駅名 |
| `--text-2xl` | 39 | 1.0 | 到着表示の残り分数（スマホは 31） |
| `--text-3xl` | 49 | 1.0 | （予備。分析の要点の数字を大きくするときだけ） |

見出しは字間を −0.01em。文はすべて sentence case。大文字だけのラベル、見出しの上の小さなラベル（eyebrow）は使わない。1 行は 80 文字以内（本文の最大幅 `68ch`）。

## 間隔と形

| トークン | 値 |
|---|---|
| 間隔の段階 | 4 / 8 / 12 / 16 / 24 / 32 / 48 px |
| `--radius-control` | 6px（ボタン、入力、切り替え） |
| `--radius-board` | 4px（到着表示の板） |
| 地図の領域・表・区切り | 角の丸みなし。影は使わない |
| 路線の帯 | 幅 6px（凡例・板・路線図の線は 4〜6px） |
| フォーカスの輪 | `outline: 2px solid var(--focus); outline-offset: 2px` |

## 動き

- 動かすのは、利用者の操作への応答（メニュー・凡例の開閉、表示の切り替え）だけ。150ms 以内
- データが古いときの帯は、出たときに 1 回だけ目立たせる（縞を 1 回流す）。`prefers-reduced-motion: reduce` では動かさない
- 到着表示の数字の毎秒の更新は動きではなく値の変化（アニメーションしない）
